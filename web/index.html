    Share Sheet shortcut

    Set it up once, then send from any app with Share → Send to PC.

    1. Open Shortcuts, tap + and name it Send to PC.
    2. Tap ⓘ to open Details, turn on Show in Share Sheet and tap Done.
    3. Add Repeat with Each: it should repeat over Shortcut Input.
    4. Inside the loop, add Get Contents of URL and paste the URL above (if it filled in Repeat Item as the URL, delete it).
    5. Tap Show More: change GET to POST, set Request Body to Form, then Add new field → File with key file and value Repeat Item.
    6. Use it: Share → scroll down → Send to PC.
